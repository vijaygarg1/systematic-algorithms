# systematic-algorithms

Companion source code for Vijay K. Garg's algorithms book series, organized by chapter (ch1, ch2, ...). Each algorithm appears in up to five languages: LLP (.llp), Java, Python, C++, and Rust.

Generated from the companion website source; see https://users.ece.utexas.edu/~garg/salgo.html for problem statements, explanations, and interactive demos.
